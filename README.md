CyberScan (webpys secan) - Python Recon & Security Scanner

A starter toolkit for port scanning, subdomain discovery, directory brute-force, and simple vulnerability checks (including basic SQLi and XSS checks). Use this scaffold to extend and integrate more advanced checks and vulnerability DBs.

Quick start:
  python main.py --target example.com --all --output reports/result
